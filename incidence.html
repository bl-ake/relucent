Incidence (combinatorial primitives)

Cubical incidence: combinatorial dual-graph and meta-graph primitives.

Every cell is identified by its sign sequence (ss). A codimension-1 face comes from zeroing one nonzero entry (a supporting-hyperplane index, or SHI). This module holds all of that combinatorics.

Who calls what:

  • Complex.dual_graph: build_dual_graph(), dual_edges_top_dim(), sync_shis_from_dual_graph().

  • Complex.meta_graph: collect_meta_face_edges(), meta_node_attrs(), the boundedness classifiers, propagate_infeasible_exclusion().

  • Complex.chain_complex: set_contracted_shis(), verify_contracted_shis().

  • certify_complex: certify_dual_graph(), verify_flip_shi_symmetry().

SHIs get assigned in three places (see docs/search_shi_and_graphs.rst):

  1. Contracted / boundary faces: seed _shis from ss_nonzero_indices(), then finish with set_contracted_shis() -> cubical_cell_shis().

  2. Meta-graph face edges (collect_meta_face_edges()): zero each ss_i != 0 and keep the edge if the face tag is a known cell.

  3. Meta-graph node metadata (meta_node_attrs()): flip-neighbor SHIs via cubical_cell_shis(), never the LP-derived poly._shis cache.

Don’t mix up the two kinds of SHI:

  • Cubical flip SHIs (cubical_cell_shis()) drive dual-graph adjacency, meta-graph node metadata, and contracted slices.

  • LP facet SHIs (shis()) are the geometric facets of ambient top cells. They can be a strict subset of the cubical set, so they must never build meta-graph edges or node metadata.

relucent.graph.incidence.assemble_face_edges_by_dim(cells_by_dim: Mapping[int, list[tuple[Any, ndarray, tuple[int, ...]]]], valid_face_tags: set[Any]) → dict[int, list[tuple[Any, Any, int]]]

Collect codimension-one face edges per dimension via collect_meta_face_edges().

Used by rebuild_meta_graph_face_edges() and as a convenience wrapper inside meta_graph().

relucent.graph.incidence.build_dual_graph(top_cells: list[Polyhedron], *, top_dim: int, ambient_dim: int, repair: bool = True) → nx.Graph[Polyhedron]

Build the combinatorial dual graph on top_cells.

Nodes are the given polyhedra; edges connect cubical flip neighbors (or 0-face-sharing neighbors when top_dim == 1). When repair is True (the default, and the only supported repair in this package), each node’s poly._shis is overwritten from the assembled edges via sync_shis_from_dual_graph() – this is the one place relucent corrects an asymmetric or stale LP-derived SHI cache.

Primary entry point for dual_graph() and certify_complex() (which may pass a pre-built graph).

relucent.graph.incidence.certify_dual_graph(graph: nx.Graph[Polyhedron], cplx: Complex, *, top_dim: int | None = None) → None

The one full dual-graph check: bidirectional SHI support + cubical face-tag consistency + sync.

Called from certify_complex() after verify_flip_shi_symmetry(). Tests import this directly for round-trip checks.

relucent.graph.incidence.classify_finite_ascending(by_dim: Mapping[int, Iterable[Polyhedron]], lookup: dict[bytes, Polyhedron], edges_by_dim: dict[int, tuple[list[tuple[bytes, bytes, int]], list[bytes]]]) → int

Classify _finite for contracted cells by an ascending sweep.

Starting from 1-dim cells (whose _finite must already be set via classify_one_cells_finite_from_face_edges()), proceeds dimension by dimension from k = 2 upward:

  • k-dim cell is unbounded if ANY (k−1)-dim face is unbounded.

  • k-dim cell is bounded if ALL (k−1)-dim faces are bounded (infeasible faces are ignored; a cell whose faces are exclusively infeasible is itself marked infeasible).

Because every (k-1)-dim cell is already classified before the k-dim pass (induction from the 1-dim base case), this single ascending sweep fully classifies all contracted cells without LP.

One pass inside classify_finite_combinatorial(), which meta_graph() calls after face edges are collected.

Returns the total number of cells newly classified.

relucent.graph.incidence.classify_finite_combinatorial(by_dim: Mapping[int, Iterable[Polyhedron]], lookup: dict[bytes, Polyhedron], edges_by_dim: dict[int, tuple[list[tuple[bytes, bytes, int]], list[bytes]]]) → int

Run classify_finite_ascending() to a fixed point.

A single ascending pass can leave cells pending when some (k-1)-faces were classified in the same pass (ordering dependency). Repeat until no progress.

Called from meta_graph() and classify_lazy_face_polys().

relucent.graph.incidence.classify_finite_lp_fallback(polys: Iterable[Polyhedron]) → int

Classify any remaining cells via Chebyshev LP (poly.finite).

Last resort in meta_graph() when combinatorial face incidence leaves cells unclassified; also used by classify_lazy_face_polys().

relucent.graph.incidence.classify_lazy_face_polys(face_tags: Iterable[bytes], lookup: dict[bytes, Polyhedron], edges_by_dim: dict[int, tuple[list[tuple[bytes, bytes, int]], list[bytes]]]) → None

Classify boundedness on lazily discovered face polys before meta nodes are added.

Invoked from meta_graph() when face-edge collection discovers sign patterns not yet present in the chain complex.

relucent.graph.incidence.classify_one_cells_finite_from_face_edges(by_dim: Mapping[int, Iterable[Polyhedron]], edges_by_dim: dict[int, tuple[list[tuple[bytes, bytes, int]], list[bytes]]], *, geometric_infeasible: set[bytes] | None = None) → tuple[int, set[bytes]]

Classify _finite on 1-cells from codimension-one 0-face incidence.

Uses face edges in edges_by_dim[1] (sign-sequence zeros), not _shis. 1-cells with no combinatorial 0-faces are checked geometrically: empty phantoms get _finite is None so truncation does not duplicate them.

First boundedness pass in meta_graph(); also used by classify_lazy_face_polys() for lazily materialized faces.

Returns (n_classified, infeasible_tags).

relucent.graph.incidence.collect_meta_face_edges(cells: list[tuple[bytes, ndarray, tuple[int, ...]]], valid_face_tags: set[bytes]) → tuple[list[tuple[bytes, bytes, int]], list[bytes]]

Return face edges (src, dst, shi) for one chunk of k-cells.

The shis tuple on each cell should come from ss_nonzero_indices(), not from propagated poly._shis.

Core edge-discovery primitive for meta_graph() (serial and parallel via parallel_collect_meta_face_edges()).

relucent.graph.incidence.cubical_cell_shis(ss: ndarray, *, neighbor_tags: set[bytes], exclude_shis: frozenset[int] | set[int] | None = None) → list[int]

Flip-neighbor SHIs: nonzero sign-sequence crossings with a same-dimension neighbor.

Authoritative flip-SHI list for meta-graph node metadata (meta_node_attrs()), contracted slices (set_contracted_shis()), and debug checks (verify_shi_flip_neighbors(), verify_meta_graph_incidence()).

relucent.graph.incidence.dual_edges_top_dim(cells: Iterable[Polyhedron], neighbor_tags: set[bytes], *, top_dim: int | None = None, prefer_cell_shis: bool = False) → list[tuple[Polyhedron, Polyhedron, int]]

Cubical dual edges for top-dimensional cells.

For top_dim == 1, pairs cells sharing a combinatorial 0-face tag. For top_dim >= 2, pairs cells that are flip neighbors across an existing ss_i != 0 crossing (combinatorial cubical adjacency).

Called from build_dual_graph(), which is in turn used by dual_graph().

relucent.graph.incidence.dual_graph_edge_top_dim(*, cell_top_dim: int, ambient_dim: int) → int

top_dim argument for dual_edges_top_dim() / verify_dual_graph_cubical().

1-cells always use flip-neighbor adjacency so _shis match flip-SHI verification. Called from build_dual_graph() and certify_dual_graph() when the complex is a contracted slice (cell_top_dim < ambient_dim).

relucent.graph.incidence.face_tag(ss: ndarray, shi: int) → bytes

Tag of the codimension-one face obtained by zeroing shi in ss.

Used throughout dual-graph and meta-graph assembly: dual edges for top_dim == 1, collect_meta_face_edges(), verify_dual_graph_cubical(), and truncation cap tagging in truncate_meta_graph().

relucent.graph.incidence.flip_tag(ss: ndarray, shi: int) → bytes

Tag of the same-dimension neighbor across hyperplane shi.

Used by _dual_edges_flip_neighbors() and cubical_cell_shis() when deciding whether a nonzero sign-sequence entry has a same-dimension flip neighbor in the slice.

relucent.graph.incidence.geometric_infeasible_one_cells(by_dim: Mapping[int, Iterable[Polyhedron]], edges_by_dim: dict[int, tuple[list[tuple[bytes, bytes, int]], list[bytes]]]) → set[bytes]

Return 1-cell tags that are geometrically empty (no Chebyshev center).

Only 1-cells with no combinatorial 0-faces need a geometric check; segments and rays are decided from face incidence alone.

Called from classify_one_cells_finite_from_face_edges() during meta_graph() boundedness labeling.

relucent.graph.incidence.meta_node_attrs(poly: Polyhedron, *, neighbor_tags: set[bytes]) → dict[str, Any]

Meta-graph node attributes. shis comes from cubical_cell_shis().

Node shis use cubical flip-neighbor SHIs, never the propagated LP-derived poly._shis cache – LP facets can be a strict subset that would silently under-report meta-graph adjacency. The meta-graph orchestrator replaces 1-cell SHIs with labels of verified 0-face incidences after face edges are assembled.

Called for every node added in meta_graph() (chain cells and lazily discovered face polys).

relucent.graph.incidence.parallel_collect_meta_face_edges(cells: list[tuple[bytes, ndarray, tuple[int, ...]]], valid_face_tags: set[bytes], *, nworkers: int) → tuple[list[tuple[bytes, bytes, int]], list[bytes]]

Parallel wrapper around collect_meta_face_edges().

Used by meta_graph() when the top-dimensional slice is large enough to benefit from multiprocessing.

relucent.graph.incidence.propagate_infeasible_exclusion(infeasible_tags: set[bytes], edges_by_dim: dict[int, tuple[list[tuple[bytes, bytes, int]], list[bytes]]]) → set[bytes]

Expand infeasible tags upward through face incidences.

Phantom (k-1)-cells with _finite is None must not appear in the meta-graph chain complex. Any k-cell that lists such a face as a boundary component is also excluded; otherwise dropping only the face edge leaves cofaces with open boundaries and breaks ∂² = 0.

Called from meta_graph() before nodes for infeasible cells are omitted from the assembled graph.

relucent.graph.incidence.set_contracted_shis(cplx: Complex, *, nworkers: int | None = None) → int

Set authoritative _shis on a lower-dimensional slice after face recovery.

Used after chain_complex() materializes a dimension slice, after boundary_complex() / boundary_cells(), and at the end of boundary discovery in finalize_boundary_complex(). Assigns cubical_cell_shis() once the full dimension slice is known. Call verify_contracted_shis() to assert flip-neighbor and symmetry invariants.

Each cell’s flip-neighbor SHIs depend only on its own sign sequence and the shared slice-wide tag set, so the cubical_cell_shis pass is embarrassingly parallel (the same shape of work as graph.vertex_star.find_vertices and topology.morse.critical_flags_for_vertices, which already farm out). It is the dominant serial cost of chain_complex() on large d=4 / deep slices, so it is farmed across a worker pool once the slice is big enough to justify Pool startup; below the gate, or in a daemon worker, it is the plain sequential loop.

Returns the number of cells whose _shis list was changed.

relucent.graph.incidence.ss_nonzero_indices(ss: ndarray) → tuple[int, ...]

All sign-sequence indices with ss_i != 0.

Used when assembling meta-graph face edges: try zeroing each nonzero entry. Also drives dual-graph flip-neighbor adjacency for top-dimensional cells.

Not used when building the contraction chain (relucent.graph.boundary._codim_one_face_kwargs() seeds candidates from this, then set_contracted_shis() finalizes). Propagated poly._shis can be a strict subset after coface intersection; using it for edge discovery omits valid faces and breaks ∂² = 0.

relucent.graph.incidence.sync_shis_from_dual_graph(graph: nx.Graph[Any]) → None

Overwrite each node’s poly._shis from the dual-graph edge shi attributes.

This is relucent’s one sanctioned repair: it replaces a possibly asymmetric or stale LP-derived SHI cache with the symmetric, combinatorially consistent set implied by the assembled dual-graph edges.

Called from build_dual_graph() when repair=True (the default for dual_graph()).

relucent.graph.incidence.verify_flip_shi_symmetry(cplx: Complex) → None

Every top-cell SHI must flip to a same-dimension neighbor that lists the SHI too.

Applies to any complex whose cells share a single dimension slice: full ambient complexes as well as contracted chain-complex slices.

First combinatorial check in certify_complex(); also invoked from verify_contracted_shis() on 1-cell slices.
